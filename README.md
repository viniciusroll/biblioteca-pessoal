# Biblioteca Pessoal

Sistema de gerenciamento de biblioteca pessoal em TypeScript, desenvolvido como projeto da disciplina de Linguagem de Programação (ADS).

## Aluno
Vinicius Rodrigo de Oliveira Silva

## Descrição
Aplicação de console que permite cadastrar livros, marcar como lidos, buscar por título ou autor, e gerar estatísticas usando arrays paralelos e métodos funcionais (`map`, `filter`, `reduce`, `forEach`).

## Como executar

npm install

npm run dev

## Funcionalidades
- Cadastro e remoção de livros
- Busca por título e autor
- Controle de status de leitura (lido/pendente) com avaliação
- Estatísticas (total, percentual lido, média, melhor avaliado, páginas lidas)
- Classificação por década
